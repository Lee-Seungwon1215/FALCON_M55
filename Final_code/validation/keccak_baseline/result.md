# sha3_cm4.s 최적화 전 M55 사이클 베이스라인

측정일: 2026-09-29. **최적화는 수행하지 않았고 원본 소스도 변경하지 않았다.**

## 기준 결과

연산비중(%)이 아니라 **독립 커널의 호출당 사이클**이다. 빈 타이머·루프 비용을 보정한 평균이며,
반올림해 표기했다. 모든 대상의 현재 속도 배율은 baseline **1.000×**이다.

| 대상 | 측정 단위 | 평균 cycles | 기준 배율 |
| --- | --- | ---: | ---: |
| `fndsa_sha3_process_block()` | SHAKE256 상태에서 Keccak-f[1600] 24라운드 1회, 분리·복원과 상태 입출력 포함 | **13,383** | 1.000× |
| 비트 분리 보조 루틴 | `bit_split_5` 4회 + `bit_split_1` 1회 | **924** | 1.000× |
| 비트 복원 보조 루틴 | `bit_merge_5` 4회 + `bit_merge_1` 1회 | **924** | 1.000× |

**포함 관계:** 13,383 cycles는 분리·복원을 포함한 전체 호출 시간이다. 세 행을 더하면 안 된다.
분리·복원 행은 원본의 호출 구성을 별도 어댑터에서 연속 호출해 측정했다.
호출자 측 상태 load/store는 제외되며, 원본 내부에서 정확하게 떼어 잰 exclusive 시간과는 구분한다.

| 개별 보조 진입점 | 처리 lane 수 | 평균 cycles |
| --- | ---: | ---: |
| `bit_split_1` | 1 | 48 |
| `bit_split_5` | 5 | 219 |
| `bit_merge_1` | 1 | 48 |
| `bit_merge_5` | 5 | 219 |

`4 × 219 + 48 = 924`. `_2/_3/_4` 진입점은 정확성 검사에는 포함했지만,
현재 원본의 SHAKE256 실제 호출 경로에서는 호출되지 않아 성능 표에서는 제외했다.
이 묶음 구성은 현재 원본의 LR/rate 처리와 관련된 실제 동작이다. 자세한 설명은 [README](README.md)에 있다.

## 조건과 재현성

- 원본: `Final_code/Before_slothy/sha3_cm4.s`.
- 보드: NUCLEO-N657X0-Q, M55 800 MHz, I/D cache OFF.
- 코드 ITCM, 데이터·스택 DTCM. 각 TCM은 256 KiB 설정.
- GCC 15.2.1 / `-O3 -mcpu=cortex-m55 -mthumb -mfloat-abi=hard -mfpu=fpv5-d16`.
- 원본의 `.cpu cortex-m4` 및 모든 ASM 명령을 그대로 유지.
- DWT CYCCNT; 측정 중 interrupt OFF; 출력은 측정 밖.
- 워밍업 5배치 후 **100표본 × 표본당 64회**. 같은 ELF로 **독립 실행 2회**.
- 함수 인수 `r=17`: SHAKE256 rate 136 bytes. FN-DSA-512/1024에 공통인 커널 기준선이다.

두 실행의 통계는 동일했다. process_block의 보정 평균은 13,383.00015625 cycles,
중앙값/최솟값은 13,383, 최댓값은 13,383.015625 cycles/호출이었다.
이는 64회 배치 중 1 cycle 차이가 있는 표본이 각 실행에 하나 있었다는 뜻이다.
보조 루틴들의 표본 사이클은 모두 같았다. 이것을 전체 상수시간 증명으로 해석하지 않는다.

| 대상 | 보정 전 cycles/호출 | 뺀 타이머·루프 비용 | 보정 후 cycles/호출 |
| --- | ---: | ---: | ---: |
| process_block | 13,386.984531 | 3.984375 | 13,383.000156 |
| split/merge `_1` | 51.015625 | 3.015625 | 48 |
| split/merge `_5` | 222.015625 | 3.015625 | 219 |
| split/merge 묶음 | 927.015625 | 3.015625 | 924 |

보정은 외부 루프·계측 비용만 빼며, 실제 함수 BL/반환 비용은 포함한다.
격리 프로젝트의 주소 배치와 호출 환경은 전체 FN-DSA 펌웨어와 다르다.
이 수치를 이전 전체 프로파일에서 역산한 함수당 추정 사이클과 혼용하지 않는다.

## 검사 결과

두 실행 모두 다음을 통과했다.

- 원본만 조립한 object와 측정 object의 원본 `.text` **4,184바이트 전체 동일**.
- 원본 생산 소스 `.c/.h/.s` 파일의 측정 전후 SHA-256 동일.
- 비트 분리/복원 `_1~5`: 5,120개 입력 조합의 oracle 비교 및 왕복 검사 PASS.
- Keccak: 독립적인 C oracle과 **1,024회 전체 25개 lane** 비교 PASS.
- SHAKE256: Python hashlib과 **7개 입력 길이, 각 256-byte 출력** 비교 PASS.
- 상태 guard PASS, CFSR/HFSR/AFSR 모두 0, TCM/ECC 설정 정상.

이번에는 변경 없는 Keccak 커널의 베이스라인만 측정했다.
FN-DSA 전체 KAT·서명검증을 새로 수행하거나 상수시간을 형식적으로 증명한 결과는 아니다.
