# Falcon·FFT·NTT·Sampling 최적화 선행연구 조사



조사 기준일: 2026-09-08



## 범위와 읽는 법



2020년부터 기준일까지 정식 학회·권호가 발표되었거나 사전공개된 관련 연구 50편을 중복 제거해 정리했다. 학회판이 있는 경우 그 연도를 우선했고 사전공개 연도는 판본 설명에 병기했다. FACCT·COSAC·Isochronous Gaussian Sampling은 2020 정식 권호/학회판이지만 2019 선공개 연구이다. 최초 공개가 2020년 이후인 연구만 필요하면 이 세 편을 제외한 47편을 사용한다.



이 문서는 1차 문헌 지도다. 모든 논문 본문을 정독하거나 코드를 실행·검증했다는 뜻이 아니다. 각 항목의 '확인 수준'을 참고한다. 출판사·ePrint·저자 기관·공식 저장소를 우선했고, 수치의 baseline과 측정 범위를 확인하지 못한 경우 정량 인용을 보류했다.



**중요:** Cortex-M55의 벡터 확장은 MVE/Helium이며 NEON이 아니다. NEON 연구의 기법은 M55에 맞는 명령·레지스터·자료형·메모리 구조로 재설계해야 한다. 'M55 적용 아이디어'와 '주의점'은 원문 실험 결과가 아니라 이 조사를 위한 분석이다.

## 먼저 읽을 20편



1. **A07 — Falcon on ARM Cortex-M4: an Update (2025)**: FP64 emulation과 native M55 비교, 함수/산술 비용 분리

2. **A05 — Benchmarking and Analysing the NIST PQC Lattice-Based Signature Schemes Standards on the ARM Cortex M7 (2023)**: native FP64를 사용한 MCU Falcon의 기존 기준점; M55 신규성 판단에 중요

3. **C04 — Polynomial multiplication on embedded vector architectures (2022)**: M55·MVE를 직접 대상으로 하므로 최우선 하드웨어 선행연구

4. **B01 — Fast and Clean: Auditable high-performance assembly via constraint solving (2024)**: M55의 적은 레지스터와 실행 지연을 모델링하는 가장 직접적인 방법론

5. **A03 — Fast Falcon Signature Generation and Verification Using ARMv8 NEON Instructions (2023)**: Falcon 전용 NEON 코드와 축소 FFT 상수표를 직접 분석

6. **C01 — Neon NTT: Faster Dilithium, Kyber, and Saber on Cortex-A72 and Apple M1 (2022)**: Falcon q=12289에 맞춘 MVE NTT 설계의 핵심 비교 연구

7. **A09 — Vectorized Falcon-Sign Implementations using SSE2, AVX2, AVX-512F, NEON, and RVV (2026)**: FP64 FFT를 유지하면서 Sampling의 정수 부분을 MVE화하는 직접 후보

8. **D02 — Isochronous Gaussian Sampling: From Inception to Implementation (2020)**: BaseSampler와 SamplerZ의 역할 및 보안 조건 이해

9. **D01 — FACCT: FAst, Compact, and Constant-Time Discrete Gaussian Sampler over Integers (2020)**: SamplerZ/BerExp 계열의 비용 분해와 정확도 요구 이해

10. **D05 — Generic, efficient and isochronous Gaussian sampling over the integers (2022)**: FP64 FFT를 건드리지 않고 SamplerZ 내부를 개선하는 직접 아이디어

11. **A02 — Fast Fourier Orthogonalization over NTRU Lattices (2022)**: 트리 사전 계산·동적 계산·메모리 절감 실험의 직접 근거

12. **A04 — Improved Key Pair Generation for Falcon, BAT and Hawk (2023)**: M55 키 생성의 출발점과 고정소수점/NTT 프로파일링

13. **C02 — Fast NEON-Based Multiplication for Lattice-Based NIST Post-quantum Cryptography Finalists (2021)**: NTT와 다른 곱셈 전략을 하드웨어 비용으로 선택하는 관점

14. **C08 — Faster Kyber and Dilithium on the Cortex-M4 (2022)**: M4 기준 구현과 M55로 가져올 수 있는 정수 산술 패턴

15. **C09 — Improved Plantard Arithmetic for Lattice-based Cryptography (2022)**: Montgomery와 비교할 Plantard의 수학적 조건과 입력 범위

16. **A06 — Optimized Falcon Verify on Cortex-M4 for Post-Quantum secure UAV communications (2025)**: 검증 NTT의 scalar 비교군과 범위 분석

17. **E01 — Formal Verification of Emulated Floating-Point Arithmetic in Falcon (2024)**: FP64 backend를 교체할 때 정확성·시험 벡터 기준 설정

18. **E02 — Do Not Disturb a Sleeping Falcon: Floating-Point Error Sensitivity of the Falcon Sampler and Its Consequences (2025)**: FMA·식 재배치·TW·fixed-point의 오차 및 KAT 검토 필독

19. **A10 — TWFalcon: Triple-Word Arithmetic for Falcon — Giving Falcon the Precision to Fly Securely (2026)**: TW의 동일 성분을 여러 독립 값에 걸쳐 MVE FP32로 묶는 연구 후보

20. **A11 — Toward a Secure Fixed-Point Implementation of the Falcon Signature Scheme (2026)**: 64/96-bit 고정소수점의 다중 32-bit 정수 MVE 설계 근거

## 연구 방향을 다시 정리하면



1. M7에서 이미 native FP64 Falcon 연구가 있으므로, 단순한 FP64 FPU 사용만을 새로운 기여라고 주장하지 않는다.

2. M55 NTT·FFT 최적화는 이미 선행연구가 있다. MVE를 쓴다는 사실 자체보다 Falcon의 수치·메모리 제약에 맞춘 구체적 변화가 중요하다.

3. FP64 FFT를 유지하면서 BaseSampler의 정수 부분을 MVE로 병렬화하는 경로를 TW/고정소수점과 독립적으로 검토한다.

4. NTT는 reduction·값 범위·layer merging·레지스터 사용량을 한 묶음으로 비교한다.

5. 새 숫자 표현과 연산 재배치에는 성능뿐 아니라 수치 오차, 분포, KAT, 비밀값 의존 실행의 확인이 필요하다.



전체 코드를 재현한 문헌 리뷰가 아니라 다음 정독·재현 대상을 고르기 위한 조사 기록이다.
