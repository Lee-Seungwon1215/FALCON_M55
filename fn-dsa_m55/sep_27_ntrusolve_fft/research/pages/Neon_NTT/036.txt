36 Neon NTT: Faster Dilithium, Kyber, and Saber on Cortex-A72 and Apple M1
Algorithm 36 qq_butterfly_mixed for interleaving 16 parallel 32-bit CT butterflies.
Inputs:
a0,...,a3, b0,...,b3, t0,...,t3, a4,...,a7, b4,...,b7, t4,...,t7, mod,
z0,l0,h0,...,z7,l7,h7, qS, sS
Roles of the symbols:
Operating registers set 1: a0,...,a3,b0,...,b3,t0,...,t3
Operating registers set 2: a4,...,a7,b4,...,b7,t4,...,t7
Registers with twiddle factors set 1: z0,...,z3
Registers with twiddle factors set 2: z4,...,z7
Indices for twiddle factors set 1: l0,...,l3,h0,...,h3
Indices for twiddle factors set 2: l4,...,l7,h4,...,h7
Modulus: mod
Specifiers: (qS,sS) = (.4S,.S)
Outputs:
(a0,b0) = (a0+ t0,a0−t0),...,(a3,b3) = (a3+ t3,a3−t3),
t4= b4ω4 mod±q,...,t7= b7ω7 mod±q
1: sub b0qS, a0qS, t0qS
2: mul t4qS, b4qS, z4sS[h4]
3: sub b1qS, a1qS, t1qS
4: mul t5qS, b5qS, z5sS[h5]
5: sub b2qS, a2qS, t2qS
6: mul t6qS, b6qS, z6sS[h6]
7: sub b3qS, a3qS, t3qS
8: mul t7qS, b7qS, z7sS[h7]
9: add a0qS, a0qS, t0qS
10: sqrdmulh b4qS, b4qS, z4sS[l4]
11: add a1qS, a1qS, t1qS
12: sqrdmulh b5qS, b5qS, z5sS[l5]
13: add a2qS, a2qS, t2qS
14: sqrdmulh b6qS, b6qS, z6sS[l6]
15: add a3qS, a3qS, t3qS
16: sqrdmulh b7qS, b7qS, z7sS[l7]
17: mls t4qS, b4qS, modsS[0]
18: mls t5qS, b5qS, modsS[0]
19: mls t6qS, b6qS, modsS[0]
20: mls t7qS, b7qS, modsS[0]
