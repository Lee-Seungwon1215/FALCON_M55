4.2.2 Input Conversion
[Por25a, Por25b] used the function fpr_of(int i) to convert an integer i into a floating-
point value. Internally, this function computes i·2x, but always for x= 0. This can be done
more efficiently by ignoring x. To determine whether a simple and efficient implementation
of fpr_of is sufficient, the input range should stay within [2−24
,224], the range of integer
values that can be exactly represented in single-precision floating-point format.
Inputs of this function are either proportional to the value of z0 from BaseSam-
pler [PFH+22, Algorithm 12], which is always in the range [0,18], or to the value of µ,
which is sufficiently small. Other inputs are 8-bit and 16-bit integers, and the value sfrom
BerExp [PFH+22, Algorithm 14]. In the latest optimized implementation, the variable
is treated as always being less than 64, since the probability of it exceeding this value is
negligible [Por25a].
