12 TWFalcon: Triple-Word Arithmetic for Falcon
Our implementation of Falcon using TW arithmetic is available at [TWF]. This
repository includes both C and ARM assembly code for all TW operations, which can be
selected via a macro in the Falcon code. The code is a modification of the latest Falcon
implementation [Por25b]. Falcon with TW passes all tests in the code, except for the
floating-point tests due to precision discrepancies when rounding from a TW to a double.
