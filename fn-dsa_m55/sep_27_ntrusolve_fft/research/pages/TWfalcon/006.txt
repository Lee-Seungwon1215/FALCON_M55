A Triple-Word Floating-Point (TW) value is defined as a triplet (x0,x1,x2) of floating-
point numbers that is P-nonoverlapping. The sequence (xi) is P-nonoverlapping when
∀i,|xi+1| < ulp(xi), where ulp(xi) is the unit in the last place defined as ulp(x) =
|next floating-point number−x|= 2⌊log2 |x|⌋·2−p+1 for precision p. The sequence (xi) is
additionally F-nonoverlapping when ∀i,|xi+1|< 1

significant place, defined as the largest power of 2 that divides xi.
As a basis for these full TW arithmetic algorithms, two main building blocks are used
to compute the sum and product of single floating-point numbers (2Sum, 2Prod). These
take two single floating-point numbers as input and return two floating-point numbers,
one representing the result of the computation (sum resp. product) and the other the
error of the computation. Additionally, a Fused Multiply-Add (FMA) operation should
be available, that multiplies two floats, and adds the result to another float, without
intermediate rounding.
To make sure the result of a computation is a TW value, the algorithms VecSum and
VSEB are used. VecSum turns a sequence of “slightly” nonoverlapping floating-point
numbers into a “more” nonoverlapping sequence. It does this according to the diagram
shown in Figure 2a and ensures that the sum of the output vector is the same as the
sum of the input vector. The output vector of VecSum is F-nonoverlapping if and only
if the input vector is sorted from biggest to smallest. Then, the algorithm VSEB puts
an F-nonoverlapping input vector into a P-nonoverlapping vector. An illustration of this
algorithm is visible in Figure 2b.
