8.2.4 Results
Table 3 compares our optimized code to prior art. For the Dilithium NTT, we compare
our 3 + 3 + 2-layer and 2 + 2 + 2 + 2-layer implementations to the 32-bit NTT from
[BBMK+21] and to the Cortex-M4 implementation from [AHKS22]. For the Kyber NTT,
we compare our 1 + 2 + 2 + 2-layer and 2 + 3 + 2-layer implementations to the Cortex-M4
implementations from [AHKS22, HZZ+22]; there is no prior implementation in Helium.
Note that the implementations from [AHKS22, HZZ+22] store the results in canonical
form, compared to [BBMK+21] and this work, which use the non-canonical order.
