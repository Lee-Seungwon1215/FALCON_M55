3.1 Stack Usage and RAM Size
Tables 3 and 5 show stack usage of Dilithium and Falcon and Tables 4 and 6
show the RAM usage of Dilithium and Falcon on ARM Cortex M7. We calculate
the stack usage by using the avstack.pl6 tool, adapted to the ARM toolchain,
and RAM was calculated using meminfo. Note that the implementations we
benchmarked weren’t optimized for low memory usage. Dilithium, for one, can
be used in much more memory constrained environments than these numbers
here suggest [GKS20].
