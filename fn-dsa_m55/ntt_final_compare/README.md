# Original M55 ref vs final NTT optimization — matched measurement

This experiment compiles the actual source directories in place:

- `ref`: `../M55_ref` (the former `fn-dsa_m55/ref`). All 30 root C/H/S
  hashes match the original 2026-09-10 source manifest. M4 assembly is ON,
  and the original RNS C receives the same GCC Cortex-M55 automatic
  optimization; this is not a forced-scalar baseline.
- `ntt_opt_slothy`: `../ntt_opt_slothy`, including both q-NTT Slothy A and
  K4-C + RNS Slothy A. No candidate source fragments are imported.

No cryptographic source is edited by this experiment. The two builds share
`app/benchmark.c`, the linker generator, startup, configuration, compiler,
input generator, timing method and host digest reference.

## Controlled memory placement

One linker script reserves the same slots in both ELFs:

- q arithmetic object text: 12 KiB starting at `0x10000400`.
- RNS arithmetic object text: 8 KiB starting at `0x10003400`.
- NTT-related object constants: 24 KiB starting at `0x30000a00`.

These are measurement-only slots, not new crypto arrays or implementation
selectors. Normal section garbage collection still applies. The linker
asserts slot bounds, ITCM low-128-KiB limit, and DTCM bounds.

`audit_layout.py` verifies that the remaining 256 named functions and 146
constant/data symbols have identical addresses and sizes; the key, signature,
scratch buffers and stack also have identical addresses. It does **not** claim
that the internal function/table offsets inside the differing object slots
are identical, or that function instructions are identical after optimization.

The empty padding is deliberately reserved equally and must not be counted as
the candidate's algorithm code/data footprint.

## Board and measurement

- NUCLEO-N657X0-Q, M55 ST-LINK `003C00223335510735383531` only.
- GCC 15.2.1, crypto sources `-O3`, same target/ABI options.
- CPU/SYSCLK/HCLK 800/400/200 MHz; I/D cache OFF; TCM ECC ON.
- Code in ITCM, constants/data/stack in DTCM, each configured 256 KiB.
  This preserves the established ECC workaround; it is not the unmodified
  upstream mlkem-native rodata placement.
- Main stack 64 KiB, interrupts/SysTick enabled; 64-bit Zephyr cycle timer.
- Per size and API: 10 fixed seed batches, 10 warmups + 10 timed calls per
  batch, i.e. 100 timed calls and 100 warmups. These are 10 unique inputs,
  not 100 independent random inputs.
- Pilot must pass for the exact ELF and source hashes before full measurement.
- q-NTT oracle/roundtrip, deterministic host output digest, normal verification,
  and modified-signature rejection are checked outside the timed block.
- The retained all-prime RNS tests were performed on the adopted sources
  previously; they are not enabled in these performance images.
- No formal CT proof, dudect or power/EM test is performed by this comparison.

## Reproduce from the workspace root

```sh
bash fn-dsa_m55/ntt_final_compare/build.sh ref
bash fn-dsa_m55/ntt_final_compare/build.sh ntt_opt_slothy
python3 fn-dsa_m55/ntt_final_compare/audit_layout.py
python3 fn-dsa_m55/ntt_final_compare/run.py ref pilot --label NEW_LABEL
python3 fn-dsa_m55/ntt_final_compare/run.py ntt_opt_slothy pilot --label NEW_LABEL
python3 fn-dsa_m55/ntt_final_compare/run.py ref full --label NEW_LABEL
python3 fn-dsa_m55/ntt_final_compare/run.py ntt_opt_slothy full --label NEW_LABEL
python3 fn-dsa_m55/ntt_final_compare/summarize.py --label NEW_LABEL
```

Board commands must run sequentially. They load sparse ELFs into RAM; no Flash
programming/erasure or M4-board operation is performed. Existing results are
not overwritten. Each accepted run archives source C/H/S, ELF, map, config,
provenance and raw log. A regenerated flat BIN spanning a 512 MiB address gap
is removed by the build helper; it can be regenerated by rebuilding.

The first pilot (`pilot-20260917T051157Z`) returned correct outputs and no
hardware fault, but its validation failed because TCM_CONTROL_START/END was
not captured. The read-only debugger capture was added; the exact same ELF
was rerun and validated. The first log is retained and excluded from results.
