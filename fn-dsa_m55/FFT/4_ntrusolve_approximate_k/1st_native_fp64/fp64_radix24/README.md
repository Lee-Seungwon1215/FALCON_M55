# R1: 24+24+16 분할

기존 16-bit 4자리 곱셈을 24+24+16의 3자리 곱셈으로 바꿨다. 계수 부분곱은 15개에서 8개로 줄이고 원본 Q32.32 결과를 유지한다. FFT 반복문과 곱셈 함수 호출 구조는 그대로다.

암호 코드는 이 폴더의 독립 소스이며 다른 후보의 코드를 include하거나
링크하지 않는다. 변경 암호 파일은 `kgen_fxp.c` 하나다.
기존 후보와 통합 ref는 보존했다.

공통 측정 harness와 단계별 최종 결과는
[R3 README](../fp64_radix24_inline/README.md) 및
[비교 결과](../fp64_radix24_inline/result.md)에 정리한다.
2026-09-22 구현 및 보드 측정 완료. 원본 KAT 300/300, 곱셈·FFT 비트
일치, keygen100/크기 및 서명·검증·변조 거부를 통과했다.
정적 검토와 입력별 timing 관찰은 전체 상수시간 증명은 아니다.
