# B 연결 구간 커널 측정 — 미채택 실험값

이 후보는 원본 키생성 KAT 294/300으로 채택할 수 없다. 아래 값은
수학적으로 동일한 원본을 대체한 최종 성과가 아니라, 연속 DS 표현의
성능·수치 특성을 조사한 실험값이다.

분모는 같은 ELF에서 실행한 원본 Q32 커널 구간이며 M55_ref/ntt_opt의
해당 고정소수점 코드가 같다.100회 평균,10회 준비,같은 입력,
입출력 Q32 변환 포함,IRQ OFF. 복사·입력 생성·검사는 시간 밖이다.

- op0: FFT→역수 준비.
- op1: FFT→준비된 역수와 점별곱→iFFT. 반복 불변 역수 준비는 시간 밖.
- op2: 분자·분모 FFT→나눗셈→iFFT. 분모 입력 복사도 원본 구간에 포함.
- 양수는 시간 감소,음수는 느려짐. 괄호는 원본/B 사이클 배율.

op0의 분모는 합성 입력 상수128/129다. 실제 NTRU의 작은 분모 민감성을
대표하지 않으며 실제 입력 fixture와 전체 KAT를 별도로 검사했다.
op1 합성 입력에서 최대 Q32 차이는3~5LSB지만 정수 반정수 경계에서
정수 k가 달라진다. 이 차이를 통과로 처리하지 않는다.
op2의 같은 합성 입력에서는 최종 k 차이0이지만 모든 입력 동등성은 아니다.

NTRU intermediate의 최대 크기는 상위1024에서 n512이며, n1024 op1은
함수 구간 자체를 비교한 확장 진단이다. depth0에서는 n512/1024를 사용한다.
작은 n16..128의 반복 구간은 원본보다 느리다. 역수 준비와 depth0의
나눗셈 감소 효과를 FFT/iFFT 단독 개선율이라고 부르면 안 된다.

8입력군 시간 시험에서 각군 내부는 대체로0~1cycle 차이, 큰 크기들의
군간 평균은 약3cycle 차이가 관찰되었다. 전체 상수시간 증명은 아니며
함수 외부 분기·측정 경로 영향까지 원인을 확정하지 않았다.
