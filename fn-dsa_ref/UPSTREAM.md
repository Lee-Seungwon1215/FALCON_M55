# Upstream reference

This directory contains the reference implementation from
[pornin/c-fn-dsa](https://github.com/pornin/c-fn-dsa), at commit
`a5f15894bf1a68017074650d5298cecf9bb29a79`.

It is tracked as ordinary source files so that the local `profiling/` tools
are included when cloning FALCON_M55. The original license is in `LICENSE`.
